# BlueTap game economy draft

This document is deliberately a draft. It does not promise a conversion rate or allocation.

## Principles

1. Blue Points are off-chain game points, not BLUEX.
2. Tapping alone must not create unlimited token obligations.
3. Season rewards must have a hard BLUEX cap chosen before claim opens.
4. Rewards should favor verified activity: retention, missions, referrals with anti-Sybil checks and wallet proof.
5. BLUEX rewards must come from an explicitly allocated treasury balance; the game should not depend on minting new supply.

## MVP points

- Tap: 1 point, constrained by energy and rate limit.
- Daily reward: 500 points.
- Successful referral: inviter 500 / new player 100.
- Tasks: fixed one-time point rewards.

## Season 1

Keep claim disabled until these are fixed publicly:

- BLUEX reward pool size
- snapshot date/time
- eligibility rules
- conversion formula
- minimum and maximum claim
- Sybil policy
- claim window

Do not advertise Blue Points as a guaranteed financial return.
